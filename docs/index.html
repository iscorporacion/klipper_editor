Klipper Editor

Ayuda y caracteristicas

Interfaz web local para editar configuraciones de Klipper/RatOS junto a Mainsail y Moonraker. Esta documentacion se puede consultar antes de instalar el editor en la impresora.

Caracteristicas

Explorador jerarquico

Navega `printer_data/config` con carpetas, iconos por tipo de archivo y acciones por archivo.

Editor con pestañas

Abre varios archivos en pestañas internas, edita texto y guarda cambios desde la interfaz.

Resaltado Klipper CFG

Colorea secciones, parametros, comentarios, macros G-code y plantillas Jinja en archivos `.cfg`.

Includes navegables

Detecta includes reales, ignora includes comentados y abre archivos relacionados sin cerrar el archivo actual.

Secciones y vista previa

Lista secciones como `[gcode_macro ...]`, permite buscar, previsualizar y saltar a la linea exacta.

Macros activas

Busca macros de la configuracion activa iniciada en `printer.cfg`, abre su origen y puede ejecutarlas por Moonraker.

Calentadores

Muestra cama y extrusores, cachea el catalogo, permite definir objetivos y enfriar desde las etiquetas.

Movimiento

Incluye home, Z Tilt si esta disponible, jog por ejes, movimiento absoluto y ajuste de Z-Offset.

Seguridad

Bloquea acciones sensibles durante impresion activa y ofrece parada de emergencia desde la barra principal.

Archivos

Permite subir archivos, crear archivos en blanco, descargar, borrar con confirmacion y ver imagenes.

Idiomas

Carga traducciones desde JSON. Ingles es el idioma por defecto y se pueden agregar otros idiomas.

Instalacion precompilada

Usa GitHub Releases para evitar compilar Next.js en impresoras con poca memoria.

Capturas

Las imagenes se publican desde `docs/help/`. Si aun no existen, se muestran los nombres esperados.

Instalacion recomendada

Instala desde una version precompilada para evitar alto consumo de memoria en la impresora. 

curl -fsSL https://raw.githubusercontent.com/iscorporacion/klipper_editor/main/install-release.sh | bash

El editor completo no puede ejecutarse en GitHub Pages porque necesita API server, filesystem local y conexion directa con Moonraker. Esta pagina publica es solo documentacion.
